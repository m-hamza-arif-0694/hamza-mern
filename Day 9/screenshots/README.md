## 🏃 How to Run Day 9 Project & Take Screenshots

1. Open terminal and navigate to Day 9:
   ```bash
   cd "Day 9"
   ```
2. Install dependencies (if needed):
   ```bash
   npm install
   ```
3. Start local development server:
   ```bash
   npm run dev
   ```
4. Open your web browser at `http://localhost:3000`.
5. Visit each URL above, press `Windows + Shift + S` (or inspect element -> `Ctrl + Shift + P` -> *Capture full size screenshot*), and save the image files inside `Day 9/screenshots/`.
