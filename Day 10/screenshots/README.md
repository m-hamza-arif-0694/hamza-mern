## 📷 Screenshots List & File Checklist

Save your captured page screenshots inside this `screenshots/` directory with the following filenames:

1. **`01_dashboard_overview.png`**:
   - **Page**: Working Dashboard Overview (`http://localhost:3000/dashboard`)
   - **Content**: Summary metric cards (Cash In/Out, Net Cash, Customer Dues), quick cash logger form, and activity feed.

2. **`02_cashbook_module.png`**:
   - **Page**: Digital Cashbook Functional Module (`http://localhost:3000/dashboard/cashbook`)
   - **Content**: Validated Cash In (+) and Cash Out (-) form, category filter pills, note search, and running cash table.

3. **`03_customer_udhar_module.png`**:
   - **Page**: Customer Udhar Book Functional Module (`http://localhost:3000/dashboard/customers`)
   - **Content**: Customer Directory list with net balance (*You Will Get* vs *You Will Give*) and You Gave/Got entry form.

4. **`04_whatsapp_reminder_modal.png`**:
   - **Page**: WhatsApp Payment Reminder Modal (`http://localhost:3000/dashboard/customers`)
   - **Content**: Accessible pop-up modal dialog with pre-filled WhatsApp dues reminder template text.

5. **`05_form_validation_errors.png`**:
   - **Page**: Form Validation System (`http://localhost:3000/dashboard/cashbook`)
   - **Content**: Inline validation error alerts when submitting negative amounts or invalid phone formats.

6. **`06_reusable_ui_components.png`**:
   - **Page**: Reusable UI Component System (`src/components/ui/`)
   - **Content**: Modular UI primitives (`Button`, `Input`, `Select`, `Card`, `Table`, `Badge`, `Modal`).

## 🏃 How to Run Day 10 Project & Take Screenshots

1. Open terminal and navigate to Day 10:
   ```bash
   cd "Day 10"
   ```
2. Install dependencies (if needed):
   ```bash
   npm install
   ```
3. Start local development server:
   ```bash
   npm run dev
   ```
4. Open your web browser at `http://localhost:3000/dashboard`.
5. Capture screenshots and save the image files inside `Day 10/screenshots/`.
