# 📸 Day 11 Project Screenshots & Submission Visuals

This directory contains the screenshots of the implemented full CRUD operations (Create, Read, Update/Edit, Delete), state handling UI, and responsive modules for the **Day 11 Capstone Submission**.

---

## 📷 Screenshots List & File Checklist

Save your captured page screenshots inside this `Day 11/screenshots/` directory with the following filenames:

1. **`01_dashboard_overview.png`**:
   - **Page**: Web App Dashboard Overview (`http://localhost:3000/dashboard`)
   - **Content**: Summary metric cards (Cash In/Out, Net Dues), connected sidebar navigation, and quick cash logger.

2. **`02_cashbook_crud_module.png`**:
   - **Page**: Digital Cashbook Module (`http://localhost:3000/dashboard/cashbook`)
   - **Content**: Cash In (+) and Cash Out (-) form, filterable transaction table, running cash balance, and entry deletion.

3. **`03_cashbook_edit_modal.png`**:
   - **Page**: Cashbook Entry Edit Modal (`http://localhost:3000/dashboard/cashbook`)
   - **Content**: Pop-up Modal Dialog for editing existing cashbook transaction entries.

4. **`04_customer_udhar_crud_module.png`**:
   - **Page**: Customer Udhar Book Module (`http://localhost:3000/dashboard/customers`)
   - **Content**: Customer Directory list displaying net balance (*You Will Get* vs *You Will Give*), phone format validation (`+923xxxxxxxxx`), and customer actions.

5. **`05_customer_edit_modal.png`**:
   - **Page**: Customer Edit Modal (`http://localhost:3000/dashboard/customers`)
   - **Content**: Pop-up Modal Dialog for updating customer profile details and balance.

6. **`06_state_handlers_ui.png`**:
   - **Page**: Application State Handlers (`http://localhost:3000/dashboard/cashbook`)
   - **Content**: UI state handlers showing Loading Skeleton, Empty State placeholder, or Error alert banner.

7. **`07_financial_reports_module.png`**:
   - **Page**: Financial Reports & Analytics (`http://localhost:3000/dashboard/reports`)
   - **Content**: Date range selector, financial statement summaries, and PDF/Excel export controls.

8. **`08_mobile_responsive_view.png`**:
   - **Page**: Mobile Viewport (375px)
   - **Content**: Mobile responsive view of the dashboard and CRUD ledger interface.

## 🏃 How to Run Day 11 Project & Capture Screenshots

1. Open terminal and navigate to Day 11:
   ```bash
   cd "Day 11"
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Launch development server:
   ```bash
   npm run dev
   ```
4. Open browser at `http://localhost:3000/dashboard`.
5. Capture screenshots and save the PNG images into `Day 11/screenshots/`.
