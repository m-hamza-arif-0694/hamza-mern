Save your captured page screenshots inside this `Day 12/screenshots/` directory with the following filenames:

## 🏃 How to Run Day 12 Project & Capture Screenshots

1. Open terminal and navigate to Day 12:
   ```bash
   cd "Day 12"
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Launch development server:
   ```bash
   npm run dev
   ```
4. Open browser at `http://localhost:3000/login` or `http://localhost:3000/dashboard`.
5. Capture screenshots and save the PNG images into `Day 12/screenshots/`.
